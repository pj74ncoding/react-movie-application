## Overview

### Motivation

To find a youtube video to show me how to do a movie application using an API.

### Learning Outcomes

- Learnt how to implement an Api using TMDB database.
- Learnt you can use the var() function in CSS to set colour themes
- Learnt about before and after pseudo‑elements
- Learnt about linear-gradient in CSS

## Project Features

- A movie list with 3 sections, Popular, Top Rated and Upcoming
- Filtering by star rating
- Drop down menu for filtering by date or rating
- Drop down menu for the order either ascending or descending
- Links to scroll to certain sections on the page
- Local storage for the colour themes
- A slider to select light or dark mode
- hover effects on each movie card to display the movie rating, release date and overview
- Click on a moviecard to go to a page with more details about that movie

## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/react-movie-application.git
cd  react-movie-application

```

### Install Dependencies

Frontend:

```bash
cd react-movie-application

npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
